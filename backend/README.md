# WorkCred Backend

Built in Phase B.

In Phase B, this directory will host the Node.js 20 + Express server with:
- `src/server.js` (Entrypoint)
- `src/app.js` (Express app configuration)
- `src/config/env.js` (Environment variable loading)
- Security middleware (Helmet, CSP, CORS, rate-limiting)
- Compression & centralized JSON error handler
- `/api/v1/health` endpoint
- MongoDB integration (Phase C)
